# 🎮 How to Access Games

## 🚀 3 Ways to Play Games:

### Method 1: From Home Page (EASIEST)
1. Start server: `npm run dev`
2. Go to: `http://localhost:3000/home`
3. Look for the **"Play Games"** card with 🎮 icon
4. Click it!

### Method 2: Direct URL
1. Start server: `npm run dev`
2. Navigate directly to: `http://localhost:3000/games`

### Method 3: From Navigation
1. Go to home page
2. Look for the purple/pink gradient card that says:
   - **"Play Games"**
   - **"Intimate games for couples"**
   - 🎮 icon

## 📍 Where to Find It

On the home page, you'll see 4 cards:
1. 💬 Start Chatting (Blue)
2. 📹 Video Call (Green)
3. **🎮 Play Games (Purple/Pink)** ← THIS ONE!
4. 📸 Share Photos (Pink)

## 🎯 What Happens Next

After clicking "Play Games":
1. Enter your name
2. Choose:
   - **Create Room** (if you're starting)
   - **Join Room** (if partner created room)
3. Share 6-digit code with partner
4. Select game: **Intimate Confessions**
5. Choose category (Seductive, Spicy, etc.)
6. Start playing!

## 🐛 Not Seeing It?

### If home page doesn't show games card:
```bash
# Restart server
npm run dev
```

### If games page shows error:
- Check browser console (F12)
- Verify server is running
- Try direct URL: `http://localhost:3000/games`

The games button is now visible on your home page. Just click and play! 💕
